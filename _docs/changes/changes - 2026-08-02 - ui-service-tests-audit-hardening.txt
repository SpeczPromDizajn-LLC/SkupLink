2. Web UI
================================================================================

Что сделано:

- Форматирование app.js / app.css / index.html / lang.js; удаление мёртвого кода.
- i18n: единицы измерения и недостающие ключи; fillSettingsForm — единая
  заливка формы настроек при boot / refresh.
- Локальные шрифты Manrope (latin + cyrillic, 400/500/600/700) и Sora

  Рядом с .woff2 лежат OFL.txt (manrope/, sora/).

  --teal, --amber, --chart-*, --muted и т.д.), а не хардкодом в JS.

  (не на «пустых» GET).
- Status pill:
    янтарный (pill-warn) — «ИБП без SNMP» / нет SNMP-данных;
    красный (pill-err)   — нет связи с сервером;
    зелёный (pill-ok)    — штатная связь.
- Убраны декоративные bg-orb из разметки/стилей.
- Синхронизация деревьев: SkupLinkService/web ↔ Linux/web
  (контролируется tests/web/web-tree-sync.test.js).

================================================================================
5. Delphi (сервис) — фиксы аудита
================================================================================

5.1. Конфиг / пароль

Проблема:
  Битый или пустой config.json мог оставлять систему без рабочего admin-hash;
  HashPassword на горячем пути Snapshot/Normalize давал лишнюю нагрузку PBKDF2
  на каждый SNMP-poll.

Что сделано (uAppConfig.pas):
  - missing/corrupt → ResetToFactoryDefaults + admin hash;
  - пустой password_hash после успешного parse → один раз HashPassword(admin)
    и persist;
  - Normalize/Snapshot не вызывают HashPassword (только AssignFrom/Load/
    factory path).

5.2. Shutdown watch

Проблема:
  После старта OS shutdown при восстановлении заряда выше порога shutdown
  не отменялся.

Что сделано (uShutdownWatch.pas):
  - AbortOsShutdown при charge_percent > shutdown_battery_percent
    (и связанные ветки восстановления сети / ухода с батареи).

5.3. Смена пароля и сессии

Что сделано (uAuth.pas):
  - ChangePassword инвалидирует чужие сессии;
  - опциональный pKeepToken сохраняет текущую сессию вызывающего.

5.4. Linux discover / NIC / settings JSON

Что сделано:
  - uNetInterfaces: getifaddrs для перечисления интерфейсов на Linux;
  - буфер имени NIC увеличен до 128;
  - невалидный settings JSON → HTTP 400 (вместо «тихого» сбоя).

5.5. HTTP статика / SNMP snapshot

Что сделано (uHttpApiServer / uSnmpUpsClient):
  - HEAD для статики: заголовки Content-Type / Content-Length без TFileStream
    на тело;
  - при ошибке опроса сброс partial SNMP snapshot → чистый offline snapshot.

5.6. Прочее hardening / cleanup

  - DEBUG-логи тихих except (вместо полного проглатывания);
  - Randomize при старте (соль/токены);
  - POSIX: sigaction вместо signal для SIGINT/SIGTERM (uConsoleApp);
  - DisplayName Windows-сервиса из одной константы STR_SERVICE_DISPLAY_NAME
    (Common.pas ↔ uWinService);
  - cleanup uses / неиспользуемых символов / FLastSnapshot.

6. Delphi (tray)
================================================================================

Проблема:
  Hint в tray не обновлялся при смене только текста (при том же mode/charge);
  HTTP-опрос API блокировал UI-поток.

Что сделано (SkupLinkTray/uMain.pas):
  - сравнение NewHint <> FHint → обновление иконки/tip при смене текста;
  - HTTP GET /api/tray в TThread.CreateAnonymousThread + TThread.Queue
    для применения результата в UI.

Синхронизация констант/моделей: SkupLinkTray/Common.pas, uApiModels.pas
(контроль tests/contracts/service-tray-sync).
