# Руководство для контрибьюторов

**Язык:** [Русский](CONTRIBUTING.md) | [English](CONTRIBUTING.en.md)

Спасибо за интерес к **SkupLink**. Мы открыты к сообщениям об ошибках, идеям и исправлениям.  
Чтобы сохранить возможность выпускать коммерческие сборки на базе этого кода, просим принять условия ниже.

## Лицензионное соглашение с контрибьютором (CLA)

Отправляя Pull Request (или иной патч) в этот репозиторий, вы подтверждаете и соглашаетесь, что:

1. Вы являетесь автором предлагаемого кода **или** имеете законное право передать права на его использование.
2. Вы предоставляете правообладателю проекта (ООО «СпецПромДизайн» и его правопреемникам) **бессрочную, безотзывную, всемирную, неисключительную, безвозмездную лицензию** на использование вашего вклада в любых целях, включая:
   - включение в открытую версию под GNU GPL v3;
   - включение в закрытые / коммерческие продукты;
   - изменение, распространение и сублицензирование.
3. Вы сохраняете авторские права на свой вклад, но даёте правообладателю использовать его **без дополнительных ограничений и без обязанности выплачивать вознаграждение**.
4. Вы гарантируете, что вклад не нарушает права третьих лиц и не содержит кода, который нельзя лицензировать на указанных условиях.

**Отдельного подписания бумаг не требуется.** Отправка Pull Request считается полным принятием этих условий.  
Если вы не согласны с CLA — не отправляйте код в этот репозиторий; можно описать идею в Issue без патча.

## Как помочь

- Сообщайте об ошибках через **Issues** (ОС, версия сборки, шаги воспроизведения, логи при наличии).
- Предлагайте изменения через **Pull Request** к основной ветке разработки.
- Один PR — одна логическая тема; большие рефакторинги лучше согласовать заранее в Issue.
- Не коммитьте секреты, локальные `config.json` с паролями, бинарники сборки и мусор IDE без необходимости.

## Стиль кода

Проект на Delphi; ориентируйтесь на уже принятый стиль в соседних модулях:

- отступы и оформление как в существующих `.pas` файлах;
- без лишних рефакторингов «заодно» с фичей;
- строки и константы — по возможности в `Common.pas` / рядом с существующими;
- веб-UI (`web/`) — правки минимальные и согласованные с текущей вёрсткой.

Сборка для проверки:

- Windows: `SkupLinkService/SkupLink.dproj` (Debug/Release), при необходимости `SkupLinkTray`;
- Linux: Release / Linux64.
